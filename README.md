# RSA download page

The public download page for RSA (Nine2Five): https://p4rk3rs.github.io/rsa-download/

Downloads are the assets of the latest release here: installers `RSA-mac-apple-silicon.dmg`, `RSA-mac-intel.dmg`, `RSA-windows-setup.exe` (the older `RSA-mac.zip` and `RSA-windows.zip` stay for links already shared).
RSA's source is private; this repo holds only the page and the built copies.
